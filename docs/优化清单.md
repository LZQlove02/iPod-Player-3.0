## 二、未处理（附原因与新建议）

| 优先级 | 问题 | 为什么没动 / 建议 |
|---|---|---|
| P2 | 专辑封面 `content://media/external/audio/albumart/<id>` 是非公开端点、卷名写死 | 已做「`albumId<=0` 不给链」；换端点（`loadThumbnail`）会改变兼容面，需真机验证 |
| P2 | EQ 每一档调节都写一次 DataStore（全量重写） | 影响很小（用户操作不密集）；若要优化，把 `setEqBands` 做 200–300ms debounce |
| P2 | `ClickWheel` 连续拖动时每个 move 事件回调一次（高刷屏 120–240Hz） | 需要按帧合并（`withFrameNanos` 或阈值），属手感改动，建议真机调 |
| P2 | `PlaybackService` 里 `exo.addListener` 的匿名监听器从不 `removeListener` | player 释放时一并回收，风险极低；顺手可改为持有引用并在 `onDestroy` 移除 |

| P3 | 无 version catalog，依赖版本硬编码（media3 重复 3 次） | 纯整洁性；引入 `libs.versions.toml` 收益中等、改动面大 |

| P3 | `app/src/androidTest` 仍然为空（依赖已配好） | 仪器测试要在设备/模拟器上跑，本环境没有 |
| P3 | `Song.dateAdded` / `size` / `mimeType` 仍是无人读取的字段；`DATE_ADDED` 单位是**秒** | 保留以便将来排序/筛选；若不用建议删除，并在字段上注明单位 |
